# 🧮 CodeAlpha Calculator

A simple and responsive **Calculator Web Application** developed using **HTML, CSS, and JavaScript** as part of the **CodeAlpha Frontend Development Internship**.

## ✨ Features

* ➕ Addition
* ➖ Subtraction
* ✖️ Multiplication
* ➗ Division
* 🔢 Number input buttons
* 🧹 AC button to clear the display
*  DEL button to delete the last digit
* 🟰 Result calculation
* ⌨️ Keyboard support
* 📱 Responsive design
* 🎨 Clean interface with pastel-colored buttons

## 🛠️ Technologies Used

* **HTML5** – Structure of the calculator
* **CSS3** – Styling, layout, and responsive design
* **JavaScript** – Calculator operations and user interaction

## 📌 Project Objective

The objective of this project is to build a functional calculator using frontend technologies and strengthen practical knowledge of **HTML, CSS, and JavaScript**.

## 🚀 How to Use

1. Open the calculator in a web browser.
2. Enter numbers using the calculator buttons or keyboard.
3. Select an arithmetic operation.
4. Press `=` or the `Enter` key to display the result.
5. Use `AC` to clear the calculation.
6. Use `DEL` or `Backspace` to remove the last input.
